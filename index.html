시작하기

개인 Developer Edition org

Headless 360 MCP 연결

  1. Setup > Integrations > API Catalog > MCP Servers에서 서버를 Activate합니다.
  2. External Client App을 만들고 OAuth 범위에 mcp_api를 넣습니다.
  3. Claude Code에서 claude mcp add로 주소를 등록하고 브라우저로 로그인합니다.

External Client App은 만든 뒤 최대 30분이 지나야 동작합니다. Developer Edition 서버 주소는 문서와 형식이 달라서 Setup 화면의 주소를 복사합니다.

https://api.salesforce.com/platform/mcp/v1/d/<My Domain>/develop/platform/headless-360
MCP 서버 Activate 공식 문서
Enterprise 평가판 org

Builder Central 켜기

  1. Setup > Builder Central(베타)에서 가용성을 켭니다.
  2. 권한 세트 Builder Central 액세스를 할당합니다.
  3. App Launcher에서 Builder Central을 엽니다.
05

주의사항

Headless 360 MCP, 개인 Developer Edition org

운영 조건

  • Beta 상태이번에도 운영 org에는 연결하지 않았습니다.
  • 과금MCP Servers 화면에 Flex Credits 과금 안내가 뜹니다.
  • API 한도Headless 360 dispatch 호출이 일일 API 요청 한도에 잡힙니다. 반영은 수십 초 늦습니다.
Headless 360 MCP, 개인 Developer Edition org

쓰기 통제

  • 승인org를 바꾸는 도구인 dispatch는 설정에 따라 승인 창 없이 실행됩니다.
  • 되돌리기데이터 스트림 활성화는 되돌릴 수 없습니다. 필드 삭제는 Beta에서 안 됩니다.
  • 변경 기록MCP로 바꾼 스트림 활성화, Data Graph, 필드는 소스나 git에 남지 않습니다.
Enterprise 평가판 org

Builder Central 조건

  • 되돌리기Publish to Org는 org에 바로 반영되고 되돌릴 수 없습니다.
  • 베타 유지베타 기간에는 7일마다 다시 방문해야 결과가 유지됩니다.
  • 지원 EditionEnterprise, Performance, Unlimited, Developer Edition입니다.
  • add-onDeveloper Edition은 add-on이 필요합니다.
